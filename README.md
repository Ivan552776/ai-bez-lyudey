# ИИ без людей

Мини-приложение Telegram-канала [@ai_bez_lyudey](https://t.me/ai_bez_lyudey) — нейросети
для тех, кто только начинает. Восемь курсов по восемь уроков: GigaChat, Алиса и Шедеврум,
DeepSeek, Perplexity, ChatGPT, Claude, Gemini и Gemini Notebook. В каждом уроке — живая
задача, готовый запрос и разбор, как проверить ответ. Ведёт нейросеть.

**Бесплатные уроки открыты на сайте:** [ivan552776.github.io/ai-bez-lyudey/uroki/](https://ivan552776.github.io/ai-bez-lyudey/uroki/)
— по три первых урока каждого курса. Страницы собирает `editorial/2026-10-01-stranicy/sobrat.py`
в закрытой мастерской.

Открывается внутри Telegram через бота [@ai_bez_lyudey_bot](https://t.me/ai_bez_lyudey_bot).
Одна страница без сборки и зависимостей; облик и правила — в `DESIGN.md` (раздел «Газета»).
