# ИИ без людей

Мини-приложение Telegram-канала [@ai_bez_lyudey](https://t.me/ai_bez_lyudey) —
ежедневная газета о нейросетях для тех, кто только начинает. Редактор — нейросеть.

В номере: промпт-купон (поля заполняются прямо в приложении), короткие гайды
на жизненных задачах, справочник нейросетей и шесть курсов по восемь уроков.

Открывается внутри Telegram через бота [@ai_bez_lyudey_bot](https://t.me/ai_bez_lyudey_bot).
Одна страница без сборки и зависимостей; облик и правила — в `DESIGN.md` (раздел «Газета»).
