# Сайт: главная `kursy/` и статьи `stati/`

Открытый сайт канала и приложения (09.10.2026). Папка начинается с `_` —
GitHub Pages её не публикует: здесь исходники и сборщик, а готовые страницы
лежат в `kursy/` и `stati/`.

| Что | Где |
|---|---|
| Главная сайта: робот гуляет по экрану, курсы, цена, статьи | `kursy/index.html` |
| Статьи о нейросетях и их главная | `stati/index.html`, `stati/<slug>/index.html` |
| Карта сайта для поиска (только эти страницы) | `sitemap-sayt.xml` |
| Превью для ссылок 1200×630 | `stati/og/<slug>.jpg` |

Числа на страницах — курсы, уроки, бесплатные уроки, цена — сборщик берёт из
`index.html` (`SECS`, строка оплаты), словарь и памятки безопасности — из
`dannye-hvost`, нейросети «открываются из России» — из `S_AI_RU`/`S_AI_MORE`.
Поменялись данные в приложении — пересобери сайт, руками числа не правь.

## Сборка

```bash
python3 _stati/sobrat.py              # страницы, sitemap-sayt.xml и строки в sitemap.xml
node _stati/oblozhki.mjs              # превью — когда добавил статью или поменял заголовок
python3 _stati/plotnyy_robot.py       # плотные позы робота — только если менялись картинки робота
```

Сборщик останавливается и ничего не пишет, если нашёл беду: битую ссылку,
пустое поле, длинный `title`, несуществующий урок или позу робота.
`--chernovik` пишет страницы и при бедах — чтобы посмотреть недописанное.

Общую `sitemap.xml` пишет сборщик уроков в мастерской
(`editorial/2026-10-01-stranicy/sobrat.py`) и затрёт наши строки.
Поэтому полный список ещё и в `sitemap-sayt.xml` — его надо один раз добавить
в Яндекс Вебмастер и Google Search Console и строкой `Sitemap:` в `robots.txt`
репозитория `Ivan552776.github.io`.

## Новая статья

Файл `_stati/tekst/<slug>.html`: шапка в комментарии и тело обычным HTML.

```
<!--
slug: kak-sdelat-chto-to          адрес: stati/<slug>/, совпадает с именем файла
kod: s-chto-to                    метка источника в приложении, до 34 знаков: «сайт: s-chto-to»
rubrika: teksty                   nachalo · vybor · teksty · rabota · ucheba · bezopasnost
poryadok: 13                      место в списке на главной статей
nachalo: 1                        (необязательно) в блок «С чего начать»
title: …                          до 75 знаков, с главным поисковым запросом
description: …                    70–170 знаков
h1: …
lead: …                           первый абзац под заголовком
kratko: …                         (необязательно) текст карточки
robot: lupa                       поза из assets/robot/, на одной странице не повторять
date: 2026-10-09
updated: 2026-10-20               (необязательно) дата правки
related: slug-1, slug-2, slug-3   «Читать дальше»
og: …                             (необязательно) короткий заголовок для превью
proverka: …                       (необязательно) строка о проверке под заголовком
-->
```

Свои метки в теле:

| Метка | Что получится |
|---|---|
| `<zapros nazvanie="…">текст</zapros>` | запрос с кнопкой «Копировать», `[скобки]` подсвечены |
| `<sravn><slabo>…</slabo><silno>…</silno></sravn>` | слабая и сильная просьба рядом |
| `<sovet nazvanie="…">…</sovet>`, `<vazhno …>` | зелёная и янтарная выноски |
| `<ol class="shagi"><li><b>…</b><span>…</span></li></ol>` | шаги с номерами |
| `<urok id="gigachat-1">` | карточка бесплатного урока: название и обещание — со страницы урока |
| `<kanal>` | приглашение в канал |
| `<prilozhenie>` | приглашение в приложение (в конце статьи оно и так есть) |
| `<faq><vopros>…</vopros><otvet>…</otvet></faq>` | частые вопросы и разметка FAQPage |
| `<neyroseti-rf>` | карточки нейросетей, что открываются из России, с датой проверки |
| `<slovar>`, `<pamyatka id="safe-data">` | словарь и памятки безопасности из приложения |
| `{D}` в ссылке | путь до корня сайта: `{D}uroki/`, `{D}stati/<slug>/` |

## Правила текста

- Как во всём продукте: на «ты», по-русски, без канцелярита.
- **Ничего не выдумывать.** Случаи ошибок нейросетей — только из наших уроков
  (раздел «Что пришло у нас»), факты о сервисах — из гида `neyroseti/` и с датой.
  Про обходные пути и VPN — ни слова (решение Ivan'а 18.09).
- Платные уроки на сайт не попадают — только ссылки на бесплатные `uroki/`.
- Картинки робота на мятном фоне первого экрана — только из `assets/robot/sayt/`:
  у обычных тело полупрозрачное и поверх надписи просвечивает.
