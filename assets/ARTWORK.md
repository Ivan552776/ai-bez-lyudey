# Картинки приложения

С 20.09.2026 приложение не показывает ни одного файла-картинки: в облике «Свет»
вместо обложек курсов стоят буквенные плитки, а вместо 3D-иллюстраций —
рисунки, собранные прямо в коде (`S_ART` в слое облика).

Поэтому удалены: шесть обложек курсов (`*-book.webp`), четыре картинки
прежнего премиум-облика (`premium-*.webp`) и `hello.png` — вместе 1,3 МБ,
которые каждый посетитель скачивал зря. Файлы и запросы к image_gen, которыми
их рисовали (`*.webp.json`), остались в истории git — коммит до 20.09.2026.
