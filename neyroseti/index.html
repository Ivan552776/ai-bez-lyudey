С чего начать, если ни разу не пробовал

Начни с той, куда у тебя уже есть вход: Яндекс ID — Алиса AI и Шедеврум, номер телефона — GigaChat. Первый запрос — не «расскажи что-нибудь», а настоящая маленькая задача: сообщение в чат, список дел, открытка. Так сразу видно, где нейросеть полезна, а где додумывает.

Как собрать такой запрос — в разборе «Как написать запрос нейросети».

Что нельзя отправлять ни в одну из них

Всё, что ты отправляешь нейросети, уходит на сервер компании и может там храниться. Поэтому правило простое: в чат — только то, что не страшно показать постороннему.

  • Паспорт, СНИЛС, ИНН — ни номером, ни фотографией
  • Номер карты, срок действия, код с обратной стороны
  • Пароли и коды из СМС — их не просит ни один честный сервис
  • Данные клиентов и коллег: имена, телефоны, адреса, суммы договоров
  • Медицинские документы с фамилией и датой рождения

Частые вопросы

Какая нейросеть лучше для начинающих?

Та, куда у тебя уже есть вход. Есть Яндекс ID — Алиса AI и Шедеврум. Есть только номер телефона — GigaChat. Хочешь попробовать вообще без входа — Z.ai.

Они правда бесплатные?

У всех восьми есть бесплатный режим — сверено по сайтам 28–30 сентября 2026. Лимиты бесплатных версий меняются, поэтому мы их не называем.

Нужна ли регистрация?

В Z.ai можно писать сразу, без регистрации. В Алисе спросить можно и без входа, но история не сохранится. Остальным нужен вход: номер телефона, почта, Яндекс ID или Google.

Можно ли пользоваться с телефона?

Да. Все восемь открываются в браузере телефона, у многих есть приложения — бери их по ссылкам с официального сайта.
