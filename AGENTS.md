# Правила для агента, который правит это приложение

Это мини-приложение Telegram: **один файл `index.html`**, ~280 КБ, без
фреймворков и сборки. Там вся разметка, стили, логика и весь текст курса.
Рядом только `sw.js` (офлайн) и `v/*.mp4` (ролики).

Пуш в `main` → GitHub Pages обновляется за 1–3 минуты → это и есть живое
приложение. Отката «одной кнопкой» нет, поэтому проверять надо до пуша.

## Обязательная проверка после любой правки JS

Синтаксис глазами не ловится. Вынуть самый длинный `<script>` и прогнать:

```bash
python3 - <<'PY'
import io,re
s=io.open('index.html',encoding='utf-8').read()
p=sorted(re.findall(r'<script[^>]*>(.*?)</script>', s, re.S), key=len)[-1]
io.open('/tmp/app.js','w',encoding='utf-8').write(p)
PY
node --check /tmp/app.js
```

**`node --check` не ловит вырезанную функцию.** После правки открыть
приложение в браузере и посмотреть консоль — иначе легко запушить
приложение, которое не запускается. Так уже было.

## Грабли, на которые тут уже наступали

- **`font:` сокращённой записью с переменной не работает.**
  `font:600 9px/1 var(--sans)` браузер отбрасывает целиком. Писать раздельно:
  `font-weight`, `font-size`, `line-height`, `font-family`.
- **Конфликты имён классов.** Прежде чем вводить класс, проверить, не занят ли
  он: `grep -o 'class="[^"]*"' index.html | sort -u`. Класс `.win` однажды
  совпал с экранами переписки — все они стали невидимыми во всех уроках.
- **`fill-mode: both` держит блок невидимым**, если анимация не проиграла
  (в вебвью Telegram это бывает). Видимость не должна зависеть от анимации.
- **Пустой `data-go=""`** воспринимается как переход на экран без имени
  и прячет всё. Атрибут надо снимать, а не оставлять пустым.
- **`window.open` в вебвью и в браузере не работает** — всплывающие окна
  запрещены, нажатие молча не делает ничего. Для ухода в Telegram есть
  готовая функция `tgGo()`; проверка «мы внутри Telegram» — `вТелеграме()`,
  смотреть на `platform !== 'unknown'`, а не на наличие `window.Telegram`:
  скрипт Telegram подключается и в обычном браузере.
- **Соседние слайды карусели видны краем**, если заполнять их лениво.
- Тап-цели не меньше 44 пикселей, это проверялось аудитом.

## Где что лежит внутри файла

| Что | Где |
|---|---|
| Разделы и уроки курса | `const SECS` |
| Разборы нейросетей | `const TL` |
| Каталог карточек | `const TOOLS`, даты сверки цен — `const СВЕРЕНО` |
| Документы (оферта и прочее) | `const DOCS` |
| Журнал обновлений | `const NEWS` |
| Отрисовка блока урока | `function blk(b)` |
| Переключение экранов | `function show(v)` |
| Проверка в конце урока | `testInit / testPaint / testAnswer` |
| Прогресс, серия дней, отметки | `markDone`, `touchDay`, `checkAch` |
| Хранилище на устройстве | обёртка `S.get / S.set` |

**Тела платных уроков в файле отсутствуют** — они на сервере и приходят
по `/api/lesson`. В `SECS` у таких уроков стоит `key`, а не `b`.

Блок проверки `['test',[вопросы]]` обязан быть **последним** в уроке.
У обычного вопроса ровно один верный вариант, у `k:'build'` — несколько.

## Язык и тон

Весь текст по-русски, без англицизмов и без канцелярита: аудитория —
непрограммисты 30–50 лет. Комментарии в коде тоже по-русски, они объясняют
**почему** так сделано, а не что делает строка. Имена переменных
по-русски в JS допустимы, **в скриптах оболочки — нет**, там zsh ломается.

## Чего не делать

- Не подключать фреймворки, сборщики и внешние библиотеки — их некуда класть.
- Не разбивать файл на части: он раздаётся как есть.
- Не трогать `v/*.mp4` и `sw.js` без причины.
- Не переписывать файл целиком «начисто»: правки точечные, иначе теряется
  то, что чинилось месяцами.
